# RAG PDF Assistant

## 📌 توضیح
یک سیستم RAG (Retrieval-Augmented Generation) که از یک سند متنی/PDF پاسخ می‌دهد، منبع (پاراگراف/صفحه) را نشان می‌دهد، و در صورت نبود جواب می‌گوید «در متن نیست». با رابط کاربری Gradio و مدل Qwen2.5-7B.

## 🎯 نتیجه
- دقت روی سوالات در متن: **۱۰۰٪**
- دقت روی سوالات خارج از متن: **۱۰۰٪**
- تعداد توهم: **۰**
- مدل: **Qwen2.5-7B-Instruct**
- رابط کاربری: **Gradio** (با لینک عمومی)
- GPU: **Tesla T4**

## 🛠️ تکنولوژی
- Sentence Transformers (Embedding چندزبانه)
- FAISS (پایگاه برداری)
- Qwen2.5-7B-Instruct (مدل زبانی)
- Gradio (رابط کاربری)
- Kaggle (GPU T4)

## 🧠 نحوه‌ی کار
۱. سند به پاراگراف/قطعه تقسیم می‌شود.
۲. هر قطعه به بردار (Embedding) تبدیل می‌شود.
۳. بردارها در FAISS ذخیره می‌شوند.
۴. سوال کاربر به بردار تبدیل می‌شود.
۵. نزدیک‌ترین قطعه‌ها با FAISS پیدا می‌شوند.
۶. قطعه‌ها + سوال به مدل ۷B داده می‌شود.
۷. مدل فقط بر اساس متن جواب می‌دهد + منبع.

## 📊 نتایج تست

| سوال | جواب | منبع | نتیجه |
|-------|-------|-------|--------|
| Transformer چیست؟ | دقیق + سال ۲۰۱۷ + مقاله | پاراگراف ۵ | ✅ |

| پایتخت فرانسه | «در متن نیست» | — | ✅ ۰ توهم |

## 📝 درس‌های گرفته‌شده
- Embedding چندزبانه برای فارسی ضروری است.
- مدل ۷B بسیار دقیق‌تر از ۱.۵B است.
- `top_k=3` گاهی منابع کمی بی‌ربط هم می‌آورد.
- Gradio در ۵ خط، یک رابط حرفه‌ای می‌سازد.
- GPU سرعت را تا ۳۰ برابر افزایش می‌دهد.

## ⚠️ محدودیت‌ها
- PDFهای فارسی گاهی متن را به‌هم‌ریخته استخراج می‌کنند (هر کلمه یک خط). برای رفع این مشکل، از فایل متنی (`.txt`) سالم استفاده شد.
- لینک Gradio فقط **۷۲ ساعت تا ۱ هفته** فعال است.
