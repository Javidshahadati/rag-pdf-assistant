# RAG PDF Assistant

## 📌 توضیح
یک سیستم RAG (Retrieval-Augmented Generation) که از یک سند متنی/PDF پاسخ می‌دهد، منبع (پاراگراف/صفحه) را نشان می‌دهد، و در صورت نبود جواب می‌گوید «در متن نیست».

## 🎯 نتیجه
- دقت روی سوالات در متن: **۵/۵ = ۱۰۰٪**
- دقت روی سوالات خارج از متن: **۱/۱ = ۱۰۰٪**
- تعداد توهم: **۰**
- زمان پاسخ: **۰.۶ تا ۱۱ ثانیه** (GPU T4)

## 🛠️ تکنولوژی
- Sentence Transformers (Embedding چندزبانه)
- FAISS (پایگاه برداری)
- Qwen2.5-1.5B-Instruct (مدل زبانی)
- Gradio (رابط کاربری)
- Kaggle (GPU T4)

## 🧠 نحوه‌ی کار
۱. سند به پاراگراف/قطعه تقسیم می‌شود.
۲. هر قطعه به بردار (Embedding) تبدیل می‌شود.
۳. بردارها در FAISS ذخیره می‌شوند.
۴. سوال کاربر به بردار تبدیل می‌شود.
۵. نزدیک‌ترین قطعه‌ها با FAISS پیدا می‌شوند.
۶. قطعه‌ها + سوال به مدل زبانی داده می‌شود.
۷. مدل فقط بر اساس متن جواب می‌دهد + منبع (پاراگراف).

## 📊 جدول ارزیابی
| سوال | نتیجه | منبع | زمان |
|-------|--------|-------|------|
| Transformer چیست؟ | ✅ | پاراگراف ۵، ۶ | ۳.۷ث |
| تفاوت BERT و GPT | ✅ | پاراگراف ۵، ۶ | ۱۱.۲ث |
| RAG چطور کار می‌کند؟ | ✅ | پاراگراف ۵، ۷ | ۵.۴ث |
| Overfitting یعنی چه؟ | ✅ | پاراگراف ۸، ۹ | ۳.۱ث |
| CNN برای چه کاری | ✅ | پاراگراف ۴، ۵ | ۱.۳ث |
| پایتخت فرانسه | ✅ «در متن نیست» | — | ۰.۶ث |

## 📝 درس‌های گرفته‌شده
- Embedding چندزبانه برای فارسی ضروری است.
- مدل دستورپذیر (Instruct) بهتر از مدل تکمیل متن است.
- فاصله‌ی بالا در FAISS (بالای ۴۰) نشانه‌ی سوال خارج از متن است.
- GPU سرعت را تا ۳۰ برابر افزایش می‌دهد (از ۳۰ث به ۱ث).
- مدل کوچک (۱.۵B) گاهی در ترجمه یا جمع‌بندی اشتباه می‌کند.

## ⚠️ محدودیت‌های PDF فارسی
PDFهای فارسی معمولاً متن را به‌صورت **هر کلمه در یک خط** استخراج می‌کنند. برای رفع این مشکل، از فایل متنی (`.txt`) یا پیش‌پردازش متن استفاده می‌شود.
